# MHGU Blender Importer

This is a Blender add-on used for importing .mod model files and .lmt animation files from Monster Hunter Generations Ultimate (MHGU / MHXX).

## Notes
1. The testing platform for this add-on is **Blender 3.6.13**. Compatibility with other versions has not been tested, but it should work in theory.
2. Before using this add-on, you must refer to Handburger's tutorials to unpack the MHGU model files and convert the .tex texture files into .png format.
3. If you do not place the .png texture files with the same name in the same folder as the .mod file, a temporary pink material will be used as a placeholder by default.
4. You need to import the .mod model file first before importing the .lmt animation file.
5. It is highly recommended not to perform non-one-to-one imports of models, armatures, and animations, as potential issues have not been tested (it is suggested to process one monster per Blender project).

---

## Instructions
1. Open Blender and create a new project.
2. Install the **MHGU-blenderImporter** add-on.
3. Menu Bar: File -> Import -> MHGU Model (.mod). Select the .mod model to import into Blender. The add-on will automatically complete the armature generation and binding, material correction, and texture information importing.
4. Menu Bar: File -> Import -> MHGU Animation (.lmt). Select the .lmt animation to import into Blender. If the model only has one set of armatures, the animation import will be completed automatically.
